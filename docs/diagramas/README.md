# Diagramas PNG

Los diagramas se generan desde los archivos Mermaid en `docs/` usando:

```bash
bash scripts/generate_diagrams.sh
```

Requiere `@mermaid-js/mermaid-cli` instalado globalmente.

Diagramas disponibles en formato Mermaid:

- [Arquitectura](../arquitectura.md)
- [ETL](../diagrama_etl.md)
- [Docker](../diagrama_docker.md)
- [Modelo ER](../modelo_er.md)
